# Practice with live audio

Use live assistance during a mock interview or another session where everyone has agreed to audio processing and AI assistance. Follow any interview, assessment, and screen-sharing rules.

1. Select one source under **Listen to**. Choose your microphone for solo practice or the Windows playback device carrying the other person's voice.
2. Set up the **Speech model** and, if you want suggestions, [choose an answer model](ai-providers.md).
3. Select **Start listening**. The Focus window shows listening, speech, a detected question, and the current answer. Use **Get answer** or turn on **Answer detected questions automatically** if everyone has agreed. When a question is missed, try **Answer what they said** or type it in the main window.
4. Use **Pause** or **Stop** when appropriate. Hiding the window pauses listening. Bring it back through the tray icon or **Ctrl+Alt+I**, then select **Resume**.

Question detection can miss short follow-ups or misread a statement as a question. Check the transcript and the current question before relying on a suggestion. Select **Transcription only** for a session without AI answers.

After stopping, save to **History** only if you want to keep the retained text. [What OpenKeet processes and stores](privacy.md)
