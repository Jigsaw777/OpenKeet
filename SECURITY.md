# Security policy

The current Windows preview on `main` is the version to check when reproducing a vulnerability. Older builds and the legacy Python prototype may differ.

Use **Report a vulnerability** on the [Security tab](https://github.com/Jigsaw777/OpenKeet/security) if GitHub offers it. Otherwise, contact the maintainer through a private channel you already have. If you need a channel, [open an issue](https://github.com/Jigsaw777/OpenKeet/issues/new) titled “Request a private security contact” and wait for the maintainer to arrange one. Include only the request for contact in the issue.

Include the affected commit or version, a description of the impact, and steps using synthetic data. Keep passwords, API keys, and real interview transcripts out of the report. If you need to share sensitive reproduction material, agree on a private transfer method with the maintainer first.

Coordinate disclosure with the maintainer. Keep exploit details out of public issues, pull requests, and Discussions.
