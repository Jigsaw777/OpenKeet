# Get help with OpenKeet

1. Start with [Windows setup](docs/getting-started.md) or [troubleshooting](docs/troubleshooting.md). For answer problems, try a typed question with an answer model connected.
2. For setup, practice, or model questions, use [GitHub Discussions](https://github.com/Jigsaw777/OpenKeet/discussions).
3. For a bug you can reproduce, a specific feature request, or a confusing page, open the matching [issue form](https://github.com/Jigsaw777/OpenKeet/issues/new/choose).

Include your Windows version, OpenKeet version or commit, and which speech or answer model you selected. Use synthetic text and redact keys, personal details, and private transcripts from screenshots or logs.

Send security issues privately using the [security reporting instructions](SECURITY.md).
